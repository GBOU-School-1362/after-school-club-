# Каталог кружков

Справочник дополнительного образования школы. Собирается из рабочей таблицы завуча, публикуется как статический сайт. Запись на кружки происходит на mos.ru — здесь только витрина.

195 кружков, 5 школьных корпусов и 5 садов, 91 педагог.

## Быстрый старт

```bash
git clone <repo> && cd kruzhki
uv run sanitize.py "~/Загрузки/Внебюджет 26-27.ods"   # только при новой выгрузке
uv run build_catalog.py data/catalog.ods
python3 -m http.server 8000
```

Открыть `http://localhost:8000`. Через `file://` не работает — `fetch` блокируется браузером.

`uv` ставит зависимости сам: они объявлены в шапке `build_catalog.py` по PEP 723, отдельное окружение создавать не нужно. Без uv: `pip install pandas odfpy && python3 build_catalog.py ...`.

**Перед первым запуском** заполните адреса зданий в `config.json` — вместо заглушек `УТОЧНИТЬ`. Пока они на месте, сборка ругается, а на сайте вместо адреса пустота.

## Как устроен репозиторий

```
config.json          школа, адреса зданий, пороги проверок — правится без программиста
overrides.json       описания и картинки, которые импорт не затирает
build_catalog.py     конвертер: .ods -> courses.json + report.txt
index.html           сайт целиком, без сборки и зависимостей
sanitize.py          вырезает служебные листы перед коммитом
check_ods.py         проверяет, что вырезаны — используется хуком и CI
scripts/             git-хуки и установщик
data/catalog.ods     очищенная таблица — единственная, что попадает в git
courses.json         результат сборки, коммитится
report.txt           замечания к таблице, коммитится
docs/                документация
```

## Исходная таблица не коммитится

Рабочий файл содержит финансовый свод, занятость залов, номера помещений и часы нагрузки. В публичный репозиторий он попасть не должен — `sanitize.py` оставляет только листы с кружками и кладёт результат в `data/catalog.ods`. Исходник закрыт в `.gitignore`.

Проверено: каталог из очищенного файла побайтово совпадает с каталогом из полного.

Защита двухуровневая. Git-хук не даёт закоммитить неочищенную таблицу локально, тот же `check_ods.py` стоит первым шагом в CI — на случай загрузки файла через браузер, где хука нет. Белый список листов берётся из `config.json`, поэтому новый служебный лист тоже будет пойман.

```bash
./scripts/install-hooks.sh
```

## Проверка перед публикацией

```bash
uv run build_catalog.py data/catalog.ods --strict
```

В строгом режиме сборка падает, если каталог выходит за пороги из `config.json`: слишком мало или много кружков, не заполнены адреса, у четверти с лишним нет кода mos.ru, в поле педагога обнаружен телефон. Этот же режим работает в CI.

## Что решение сознательно не делает

Не собирает персональные данные посетителей: нет форм, нет аналитики, нет внешних шрифтов. Не дублирует запись — только ссылка на портал. Не заводит собственную базу: источником остаётся таблица, которую школа ведёт для своих нужд.

Подробнее — в [ARCHITECTURE.md](docs/ARCHITECTURE.md), раздел «Чего в решении нет».
