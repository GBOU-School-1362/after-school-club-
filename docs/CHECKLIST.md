# Чек-лист развёртывания

Пройти один раз при первом запуске. Порядок важен: пункт 1 нельзя откатить после пуша.

## Перед первым коммитом

- [ ] **Заполнить адреса в `config.json`.** Восемь зданий помечены `УТОЧНИТЬ`: Б6, Щ36, БЖ9, М12, М46, Щ22, В28А, З31А. Точные адреса — на сайте школы в разделе «Контакты» или в уставе, где перечислены места осуществления образовательной деятельности.

- [ ] **Указать школу и телефон приёмной** в `config.json` → `school`, `contact`. Телефон в формате `+7...` для `phone` и человеческий для `phoneLabel`.

- [ ] **Очистить таблицу.**
  ```bash
  uv run sanitize.py "~/Загрузки/Внебюджет 26-27.ods"
  python3 check_ods.py data/catalog.ods
  ```
  Должно вывести «чисто» и перечислить шесть листов.

- [ ] **Собрать в строгом режиме.**
  ```bash
  uv run build_catalog.py data/catalog.ods --strict
  ```
  Должно завершиться словами «Проверки пройдены». Если ругается на адреса — вернуться к первому пункту.

- [ ] **Посмотреть сайт локально.**
  ```bash
  python3 -m http.server 8000
  ```
  Проверить: адреса видны в карточках, фильтр по зданию показывает улицы, счётчик меняется при клике по направленности, кнопка «Найти на mos.ru» открывает поиск с этим кружком в выдаче.

- [ ] **Решить вопрос с доменом и владельцем репозитория.** Если репозиторий и домен оформлены на частное лицо, школа потеряет сайт при его уходе. См. [PRIVACY.md](PRIVACY.md), раздел «Правовой статус».

## Первый коммит

- [ ] **Инициализировать и поставить хук.**
  ```bash
  git init -b main
  ./scripts/install-hooks.sh
  ```

- [ ] **Проверить состав коммита.**
  ```bash
  git add .
  git status
  ```
  В списке **не должно быть** `data/Внебюджет*.ods`. Это последний момент, когда лишний файл убирается без переписывания истории.

- [ ] **Закоммитить.**
  ```bash
  git commit -m "Каталог кружков"
  ```
  Хук проверит `.ods` и остановит коммит, если в таблице остались служебные листы.

## GitHub

- [ ] **Создать репозиторий.**
  ```bash
  gh repo create kruzhki --public --source=. --push
  ```
  Без `gh`: создать пустой репозиторий на github.com (без README и .gitignore), затем
  ```bash
  git remote add origin git@github.com:ЛОГИН/kruzhki.git
  git push -u origin main
  ```

- [ ] **Включить Pages.** Settings → Pages → Source: Deploy from a branch, ветка `main`, папка `/ (root)`.

- [ ] **Открыть сайт** на `https://ЛОГИН.github.io/kruzhki/` и проверить, что `courses.json` загрузился.

- [ ] **Проверить Actions.** Вкладка Actions → workflow «Сборка каталога» → Run workflow. Должен пройти и открыть Pull Request либо сообщить, что изменений нет.

## После запуска

- [ ] **Отдать завучу два списка** из `report.txt`: 50 кружков без кода mos.ru и те, у кого не разобралось расписание.
  ```bash
  grep 'нет кода' report.txt
  grep 'нет расписания' report.txt
  ```

- [ ] **Попросить починить колонку «Возраст»** в исходной таблице: выделить → Формат ячеек → Числа → Текст → ввести значения заново. Иначе порча продолжит накапливаться, см. [DATA.md](DATA.md).

- [ ] **Передать школе инструкцию** — первая часть [OPERATIONS.md](OPERATIONS.md), она написана для сотрудника без технического опыта.

- [ ] **Согласовать с директором**, что сайт справочный и официальным сайтом школы не является.

## Если что-то пошло не так

Полный файл случайно закоммичен и запушен — удаления в новом коммите недостаточно, старая версия достаётся из истории одной командой. Нужен `git filter-repo` и принудительный пуш, и даже это не гарантия, если репозиторий успели склонировать. Поэтому пункт «проверить состав коммита» стоит в списке отдельной строкой.
